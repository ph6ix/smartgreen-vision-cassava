# 🍠 สมาร์ทกรีน Vision Ai วิเคราะห์ใบมันสำปะหลัง

ถ่ายภาพใบมันสำปะหลัง 3 ตำแหน่ง (+ ทั้งต้น ไม่บังคับ) ให้ AI (Gemini) ช่วยประเมิน
- **ธาตุอาหาร 8 ธาตุ**: N, P, K, Mg, Ca, Zn, B, Fe
- **โรคและแมลง**: โรคใบด่างมันสำปะหลัง (CMD), เพลี้ยแป้ง, ไรแดง, แมลงหวี่ขาว, ใบจุดสีน้ำตาล, ใบไหม้ (CBB), แอนแทรกโนส, หัวเน่า ฯลฯ
- **แผนปุ๋ย** ต่อไร่ตามอายุและชนิดดิน และสิ่งที่ควรทำทันที

เว็บ: https://smartgreen-vision-cassava.vercel.app · หน้าแรกรวมพืช: https://smartgreen-vision-ai-home.vercel.app

> ⚠️ ความรู้อ้างอิงและสูตรปุ๋ยในคำสั่ง AI (`lib/cassavaService.js`) เป็น **ร่าง** จากหลักวิชาการทั่วไป
> ต้องให้ทีมนักวิชาการสมาร์ทกรีนตรวจทานก่อนเปิดใช้กับลูกค้า

## ตำแหน่งภาพ

| ช่อง | ตำแหน่ง | ใช้ดู |
| --- | --- | --- |
| `young` | ใบยอด / ใบอ่อน | Zn, B, Fe · โรคใบด่าง เพลี้ยแป้ง |
| `mature` | ใบมาตรฐาน (ใบแรกที่คลี่เต็มที่นับจากยอด) | ตัวแทนสถานะธาตุอาหารของต้น |
| `old` | ใบล่าง / ใบแก่ | N, K, Mg · ใบจุด ไรแดง |
| `tree` (ไม่บังคับ) | ทั้งต้น / ลำต้น / หัว | ทรงต้น ยอดหงิก ลำต้น/หัวเน่า |

## โครงสร้าง

| ส่วน | หน้าที่ |
| --- | --- |
| `public/` | หน้าเว็บ: `index.html` (ตรวจใบ), `report.html` (ใบรายงาน A4 + บันทึกรูป), `js/`, `css/`, `assets/` |
| `api/analyze.js` | ฟังก์ชัน Vercel: รับภาพ → `lib/cassavaService.js` |
| `api/save-sheet.js` | บันทึกผลลง Google Sheets (`lib/sheets.js`, `gas/Code.gs`) |
| `lib/cassavaService.js` | คำสั่ง AI, ตรวจภาพก่อนวิเคราะห์, จัดรูปผล |
| `lib/cassavaProducts.js` | ผลิตภัณฑ์สมาร์ทกรีนที่อนุญาตให้ AI แนะนำ (ตอนนี้ว่าง รอฝ่ายวิชาการ) |
| `lib/gemini.js`, `lib/modelRetry.js` | เรียก Gemini พร้อมลองใหม่อัตโนมัติเมื่อระบบหนาแน่น |
| `server.js` | เปิดเว็บทดสอบในเครื่อง http://localhost:8080 |

## ตั้งค่า Vercel (Environment Variables)

| ชื่อ | ค่า |
| --- | --- |
| `GEMINI_API_KEY` | คีย์ Gemini (ใช้ตัวเดียวกับแอปอ้อย/ปาล์มได้) |
| `GOOGLE_SHEETS_WEBHOOK_URL` | (ไม่บังคับ) URL เว็บแอปจาก `gas/Code.gs` ของชีตมันสำปะหลัง |

## รันในเครื่อง

```bash
cp .env.example .env   # ใส่ GEMINI_API_KEY
npm install
npm start
```

## เพิ่มผลิตภัณฑ์สมาร์ทกรีน
แก้ `lib/cassavaProducts.js` ตามตัวอย่างในไฟล์ และวางรูปสินค้าไว้ที่ `public/assets/`
